# R4：難しさと説明の調整

作成日：2026-09-27（日本時間）  
基準：PR #9マージ後のmain `840606d1d7df577cb4feb39e7f917c2e3d68a021`

## 変更した動作

- 成功数の境界を固定した20段階へ更新しました。段階20の後も最終段階の値で攻撃を生成し、成功数が増えても配列外参照や難易度の後退は起きません。
- 第7段階（成功20）から2連、第13段階（成功46）から3連を抽選候補にしました。タップ確率は段階表に固定し、各段階で合計1になります。
- 表示時間は980msから440ms、攻撃間隔は1080msから540msへ段階的に調整し、速度ジッタは0から0.35まで増やします。実際の生成値と分割間隔にも安全な下限を設けています。
- 2連・3連の開始時に「何回攻撃に備えるか」を日本語バナーで知らせ、攻撃中は必要回数と残り回数を表示します。完了・画面離脱・停止中は表示を消します。
- 分割攻撃でも1攻撃で失うHPは最大1の既存ルールを維持しました。表示用のUIフックはゲーム進行へ影響せず、動きを抑える設定でも判定・速度・得点は変わりません。
- 難易度の変更で得点分布が変わるため、自己ベストのルール版を `r4-difficulty-20260927` に更新しました。`r3-practice-20260927` など旧キーは削除・移行せず残します。
