# R7 リリース体験調整記録

更新日：2026-09-28（日本時間）

## 対応内容

- 遊び方を端末種別で切り替えた。スマホでは5つの画面ボタン、PCでは画面ボタンまたはキーボードを案内する。
- 入力方向の失敗を、攻撃方向と同じ入力の「逆方向」と、それ以外の「方向が違う」に分けた。
- ランクを10段階へ変更した。Sの境界を32,000点へ移し、Sへの早すぎる到達を抑えた。
- ホームのシェア文を次の2行へ固定した。

  ```text
  パリパリ：来た方向と反対を、タイミングよく選べ！
  https://chameleonjp-lab.github.io/paripari/
  ```

- 実際のゲームプレイ中スクリーンショットから、1200×630のSNS用画像を作成した。中央に実ゲーム画面を置き、周囲にも同じ画面の色と光を使って、存在しないゲーム要素を加えていない。
- 外部音声ファイルを使わず、短いSEを端末内で生成する。攻撃出現、カウントダウン、開始、ぴったり、成功、失敗、ゲーム終了を対象にし、設定から効果音を切れるようにした。

## 検査

- `npm test`: 55件の境界値検査と67件のNode検査が成功
- `npm run build`: `dist/paripari.html`を再生成
- `npm run build:check`: 生成物と分割ソースの一致を確認

GitHub Actionsの最終確認と公開ページの確認は、Draft PR作成後に行う。
