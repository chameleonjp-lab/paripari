# R5：公開候補の検証

作成日：2026-09-27（日本時間）  
基準：PR #10マージ後のmain `2a0c5411e4148c51993fbd4729b2daa6072be144`

## 目的

R4までに実装したゲームを、公開候補として長時間動かしたときにも状態が壊れないか確認します。R5では公開操作、ランキング連携、データベース変更、正式URLの確定は行いません。

今回の検査では、次を自動で確認します。

- 分割版と単一HTML版で、外部へのスコア送信や不要な外部通信がないこと
- 固定乱数と仮想時刻による長時間相当の連続プレイで、攻撃・入力・時計が増え続けないこと
- 実際の画面操作で100回の結果→再挑戦を繰り返し、各試合の結果識別子、入力キュー、攻撃参照、画面要素、タイマー・描画予約が次の試合へ不正に残らないこと
- 既存の単体検査、生成物一致、Chromium/WebKit検査をR5でも維持すること

## 変更

`tests/release-r5.test.mjs` に、ゲーム状態・時計・試合管理を使った再現可能な長時間相当検査を追加しました。実時間30分は待たず、仮想ゲーム時間を進めます。実ブラウザでしか確認できない画面遷移は、`tests/browser.mjs` のR5再挑戦ストレス検査で分割版・単一HTML版の両方を確認します。

検査用のゲーム参照は既存のブラウザ検査フックから一時的に注入します。配布HTMLや通常の本番コードへ検査用APIを追加しません。

## 受入検査との対応

| 対象 | R5で確認すること | 実施方法 |
| --- | --- | --- |
| Q01 | 外部スコア送信・ランキング照会がない | ブラウザの通信観測と既存の共有フォールバック検査 |
| Q02 | 長時間相当の進行、100回再挑戦、停止・再開後の状態保持 | 固定乱数・仮想時刻のNode検査と、Chromium/WebKitの実画面検査 |
| Q03 | 新しい環境で既存検査・生成・両形式を通す | GitHub ActionsのQualityで確認 |
| Q04 | 実装と分離したレビューで重大な未解決事項を確認 | Sol Highの読み取り専用レビューと修正後の再確認 |

## 検査結果

- `npm test`：91件合格（既存スクリプト33件、Nodeテスト58件）
- `npm run build` / `npm run build:check`：成功。分割ソースと配布HTMLの一致を確認
- `node --check tests/browser.mjs tests/release-r5.test.mjs`：成功
- PR #10マージ後のmain Quality #18：成功（Chromium、WebKit、verifyを含む）
- R5のブラウザ100回再挑戦：Draft PRのGitHub Actionsで分割版・単一HTML版、Chromium/WebKitを確認する
- 独立レビュー：提出前にSol Highの読み取り専用レビューを実施し、結果を追記する

ローカル環境でPlaywright本体を導入できない場合、ローカルブラウザを合格扱いにせず、GitHub Actionsの結果と分けて記録します。

人による体感確認、iPhone 17 Pro Safari実機確認、公開予定URL・プレビュー画像の最終確認はR5の自動検査では代替しません。これらは未実施として残し、R6の公開準備で扱います。
