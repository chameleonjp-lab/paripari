# R6：公開準備

作成日：2026-09-27（日本時間）  
基準：R5マージ後のmain `09a450dfa31f3303fb50d58c6aebb872eda3faa8`

## 目的

R6では、公開設定を変更せずに、公開前に確認できるものを整理します。正式URLの設定、GitHub Pagesなどの公開元の変更、実験場への掲載、ランキング登録、実際の公開は、この記録の対象外です。ユーザーの明示指示があるまで行いません。

## 今回確認する範囲

| 対象 | 状態 | 根拠・残りの確認 |
| --- | --- | --- |
| 配布物 | 自動検査で確認する | `npm run build:check` とQualityで分割ソースとの一致を確認する |
| ライセンス | `LICENSE` を追加 | `package.json`のMIT指定と本文をそろえる |
| 正式URL | 未設定を維持 | `src/js/platform.js` の `OFFICIAL_GAME_URL` は空欄。公開先を推測しない |
| 公開予定パス・公開元 | 未確認 | 現在の設定を変更せず、ユーザーの公開指示後に確認する |
| プレビュー画像 | 未作成 | 実ゲームの最終画面を確認してから作成する |
| iPhone 17 Pro Safari | 未実施 | 実機での確認が必要。模擬画面やWebKit検査を実機確認とは扱わない |

- `npm run build:check`：成功。分割ソースと配布HTMLの一致を確認
- `LICENSE`：MIT本文を確認。`package.json` のライセンス指定と一致
- マージ後main Quality #22：Chromium、WebKit、verifyが全件成功
- R6 Draft PR #12 Quality #23：Chromium、WebKit、verifyが全件成功
- Sol High相当の独立レビュー：承認、必須修正なし

この自動検査は、iPhone Safariの実機操作、正式URL、公開元、プレビュー画像の確認を代替しません。

## 公開保留の理由

- 正式な公開URLと公開元を確認していない。
- iPhone 17 Pro Safariの実機確認を行っていない。
- 実ゲームの最終画面を使ったプレビュー画像を作成していない。

したがって、この工程で「公開可能」「実機確認済み」とは報告しません。R6の自動検査が通っても、上の未実施項目は残ります。

## 変更しないもの

ランキング連携、外部へのスコア送信、データベース、公開設定、既定ブランチ、正式URL、実験場の一覧は変更しません。
